WHAT IS E-NEST

네스팅(Nesting)이란, 강판 위에 부재를 최적으로
배치하는 작업입니다

선박·철구조물을 만들 때는 수백~수천 개의 금속 부재(판재, 형강, 평철)를 강판에서 잘라냅니다. 이때 부재들을 강판 위에 얼마나 빈틈없이 배치하느냐가 원자재 손실과 직결됩니다. 이 배치 작업을 네스팅이라고 합니다.

E-NEST는 이 네스팅 전 과정을 자동화하는 소프트웨어입니다.

WHY NESTING SOFTWARE

강재 낭비율 1%가 연간 수억 원의 손실입니다

01

수작업 배치의 한계

판재·형강·평철은 형상이 모두 다릅니다. 수백 개 부재를 사람이 직접 배치하면 강재 이용률이 낮아지고 잔재가 늘어납니다. 조선·금속 가공에서 강재비는 전체 원가의 상당 부분을 차지하므로 배치 효율은 곧 수익성과 직결됩니다.

02

열 변형과 절단 순서

절단 순서가 잘못되면 강판에 열이 누적되어 부재가 뒤틀립니다. 재작업·불량이 발생하고 후공정 일정이 밀립니다.

03

CAD-NC 연결 단절

설계 CAD에서 만들어진 부재 데이터를 DNC 시스템을 통해 절단 장비까지 오류 없이 전달하는 것이 수작업으로는 번거롭고 누락 위험이 큽니다.

CORE TECHNOLOGY

E-NEST를 구성하는 3가지 핵심 기술

단순 배치 툴이 아닙니다. 산업 현장의 요구를 해결하는 3개의 핵심 라이브러리가 E-NEST를 완성합니다.

자동 배치 알고리즘
Auto Nesting Algorithm
원리

철판 하나에 수백 장의 부품을 배치할 때, 유전 알고리즘(Genetic Algorithm)을 사용하여 자재 낭비를 최소화하는 최적 배치를 컴퓨터가 자동으로 찾아냅니다.

왜 필수인가

배치 효율이 곧 수익성입니다. 알고리즘 성능이 강판 한 장에서 더 많은 부재를 뽑아내어 잔재와 재고 자재를 줄입니다.

잔재 모양 계산
Scrap Geometry Calculation
원리

철판을 다 자르고 나면 복잡하게 구멍이 뚫린 잔재(고철)가 남습니다. 컴퓨터가 이 복잡한 잔재 모양을 정확히 계산·저장합니다.

왜 필수인가

작은 부품을 새로 만들 때 새 철판을 쓰지 않고 저장된 잔재에 자동으로 배치하여 재활용합니다. 자재비를 한 번 더 줄이는 핵심 기능입니다.

텍스트 자동 정렬
Auto Text Arrangement
원리

철판의 각 조각에 "어디에 들어갈 부품인지" 마킹 장비가 글씨를 새겨야 합니다. E-NEST는 이 글자들이 서로 겹치거나 부품 선 바깥으로 삐져나가지 않도록 자동 정렬합니다.

왜 필수인가

글씨가 뭉개지면 현장 조립에서 부재를 특정할 수 없습니다. 이 기능이 없으면 마킹 오류가 곧 조립 오류로 이어집니다.

E-NEST V EXCLUSIVE

형강 가공을 완성하는 V버전 3대 기능

대형 CAD 시스템 없이 단독 실행되는 E-NEST V만의 전용 기능입니다. 반복 가공 작업의 효율과 현장 도면 품질을 동시에 높여줍니다.

01

Endcut · Hole · Marking
매크로 3종 세트

가공 매크로 (Macro)

원리

형강 끝부분을 비스듬히 자르거나(Endcut), 나사 구멍(Hole)을 뚫거나, 마킹 패턴을 새기는 작업을 매번 새로 그리지 않습니다. "A타입 엔드컷", "30파이 구멍" 처럼 형상을 매크로(템플릿)로 등록해두고, 한 번의 명령으로 수백 개 부재에 일괄 적용합니다.

왜 필수인가

클릭 한 번으로 수백 개의 구멍·끝단 가공을 일괄 적용할 수 있어 설계 작업 시간을 대폭 줄입니다. 규격이 바뀌면 매크로 정의 하나만 수정하면 전체 부재에 자동 반영됩니다.

02

Web · Scallop
자동 시공

구조 안전 (Structural Safety)

원리

철골 뼈대가 십자로 만나는 부분은 용접부에 응력이 집중되어 균열이 발생하기 쉽습니다. 이를 방지하기 위해 모서리에 동그란 홈(Scallop)을 파는데, E-NEST V는 Edge · Corner · Weld 3가지 타입과 상단·중단·하단 위치를 조합해 Scallop 위치를 자동으로 계산·시공합니다.

왜 필수인가

Scallop 위치가 잘못되면 용접 불량이 발생하고 피로 파괴로 이어집니다. 수작업 계산은 오류와 누락 위험이 크지만, 자동 시공은 규격에 맞는 Scallop을 누락 없이 배치하고 도면 Symbol까지 자동 생성합니다.

03

Member 가공도 · BOM
자동 출력

도면 자동화 (Drawing Automation)

원리

형강 가공이 완료되면 현장 작업자가 보고 기계를 작동할 상세 가공도(Member MCP)와 부품 리스트(BOM 표)를 컴퓨터가 자동으로 양식에 맞춰 생성합니다. 개선(Bevel) 상세 확대도, 치수 기입, 부품 마킹 텍스트 정렬까지 자동 처리됩니다.

왜 필수인가

설계자가 수동으로 도면을 정리해 넘길 필요가 없습니다. 휴먼 에러가 사라지고 현장 전달 속도가 빨라집니다. PDF·DXF 출력을 지원하므로 별도 CAD 뷰어 없이 현장에서 즉시 확인 가능합니다.

Q

자동 네스팅의 실제 자재 이용률은?

강재 조건에 맞춰 자재 이용률을 높이도록 자동 최적화합니다. E-NEST의 자동 네스팅은 유전자 알고리즘(Genetic Algorithm) 기반으로 판재·평철·형강 각각의 특성에 맞게 패턴·페어링을 개별 최적화합니다. Pre-Nesting(자재 발주용)과 Production Nesting(실생산용)을 분리해 발주 단계부터 이용률을 관리합니다. 구체적 수치는 현장 강재 규격 조건 기준으로 별도 안내 가능합니다.

Q

ERP·MES와 연동이 가능한가요?

가능합니다. 설계·생산 시스템에서 받은 데이터를 NC/DWG 출력과 DNC 전달까지 연결합니다. E-NEST는 AM(Aveva Marine) / ERP / PLM 시스템에서 Gen 파일 및 BOM 데이터를 읽어 부재를 생성합니다. 네스팅·절단 경로 결정 후에는 NC 데이터와 도면을 DNC 시스템으로 직접 전달하는 파이프라인을 갖추고 있습니다. NC 출력 포맷은 ESSI·EIA 규격을 지원하며, 여러 장비를 같은 라인에서 운용하는 환경에도 대응합니다. MES 연동 상세 범위는 현장 요구사항 기준으로 별도 협의합니다.

Q

장비가 바뀌면 개발사에 다시 의뢰해야 하나요?

장비별 NC 출력 규칙을 분리해 관리할 수 있어 장비 변경 대응이 빠릅니다. E-NEST V의 Post Processor는 Lua·Python·VBScript 스크립트 기반입니다. NC 출력 규칙을 스크립트 파일로 분리해두었기 때문에, 장비가 바뀌어도 현장 조건에 맞춰 포스트 프로세서를 조정할 수 있습니다. 여러 포스트 프로세서를 동시에 실행하는 것도 지원합니다.
